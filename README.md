# 📸 PixelPulse - Next-Gen Stock Photography Portal

PixelPulse is a high-performance, responsive web application built with Vanilla JavaScript, HTML5, and CSS3. It directly integrates the **Unsplash REST API** to deliver an immersive HD stock photography search experience.

## ✨ Key Upgrades & Features
- **Live Unsplash REST API Integration:** Real-time search functionality across millions of dynamic HD stock images.
- **Direct HD Blob Downloads:** Built-in asynchronous download function that directly fetches images as Blobs to avoid cross-origin redirects.
- **Infinite Scroll & Pagination:** Optimized event listeners to dynamically load more images as the user scrolls.
- **Skeleton Shimmer UI:** Smooth loading placeholders that elevate user experience (UX) during API fetch cycles.
- **Interactive Lightbox Modal:** Instant modal preview featuring image resolution metadata, author credits, and HD source access.
- **Clean Responsive Glassmorphism Design:** Styled using CSS Flexbox, Grid, and translucent UI elements with zero external CSS frameworks.

---

## 🛠️ Tech Stack & Concepts
- **Frontend Core:** HTML5, CSS3 (CSS Grid, Flexbox, Keyframe Animations)
- **Programming Logic:** JavaScript (ES6+, Fetch API, Promises, Async/Await, DOM Manipulation)
- **API Handling:** Unsplash Developer REST API
